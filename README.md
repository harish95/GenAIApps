# GenAIApps
## Text-to-SQL Query Generator
Built a natural language to SQL query converter using Gemini API, enabling non-technical users to query databases efficiently.

## Invoice Information Extractor
Developed an AI-driven tool to extract key fields (vendor, amount, date, line items) from PDF invoices, improving data processing automation.

## PDF Q&A Assistant
Created a question-answering system on top of PDF documents using Gemini API, providing quick, context-specific answers from large documents.

## Resume Analyzer
Built a GenAI-powered application to assess resumes against job descriptions, delivering insights on skill alignment and optimization recommendations.
